# 00 · Индекс памяти

Читай только то, что нужно задаче. Весь набор файлов за один запрос не читается.

| Файл | Когда читать | Объём |
|---|---|---|
| `01-legacy.md` | перед портом фичи: формы, БД, бизнес-правила | ~100 строк |
| `02-target.md` | архитектура и конвенции WPF | ~80 строк |
| `03-porting.md` | перевод VB/WinForms → C#/WPF, рецепты | ~100 строк |
| `04-progress.md` | статус, порядок работ, следующий шаг | ~60 строк |
| `05-decisions.md` | принятые решения и открытые вопросы | ~60 строк |
| `features/_template.md` | создать карточку фичи перед кодом | ~40 строк |

## Маршрутизация
- Новая форма/сценарий → `01` + `03`, затем карточка фичи.
- UI/стиль/навигация → `02`.
- Ошибка сборки/непонятный VB → `03` + `04`.
- Спорное архитектурное решение → `05`, добавь ADR.
- Статус/что дальше → `04`.

## Правила памяти
- Карточка фичи — главный источник для реализации; легаси перечитывать только для уточнений.
- Держи карточку < 100 строк: контролы, события, SQL, формулы, edge cases.
- Обновляй статус после каждой сессии; не отмечай «готово» без сборки и проверки сценария.
- Не дублируй код легаси; ссылайся на `файл:строки`.
