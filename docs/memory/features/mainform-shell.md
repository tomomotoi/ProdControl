# Feature: mainForm (оболочка) + каркас M0

- Легаси: `mainForm.vb` (1-340), `mainForm.Designer.vb` (26-312 — только меню)
- Цель: `MainWindow` / `MainWindowViewModel`
- Статус: в работе (сборка и запуск проверены, утилиты вручную не проверены)
- Зависимости: `INavigationService`, `IDialogService`, `IDatabaseMaintenanceService`, `ICurrentDayStore`, `IDbConnectionFactory`, `OperationLog`

## 1. Назначение и сценарии
Главное окно приложения: меню разделов, запуск дочерних экранов, утилиты обслуживания БД.
Успех — меню повторяет легаси, утилиты выполняют те же файловые операции и сообщения.
Дочерние формы ещё не портированы: пункты меню открывают экран-заглушку с названием раздела.

## 4. Данные
- Таблицы/поля: `OperationLog` (только полная очистка).
- SQL: `DELETE FROM OperationLog` (без пользовательских значений).
- Чтение/запись: `OleDbConnection` через `IDbConnectionFactory`; `App.config` → `OperationDB`.
- Файлы: `OperationDB.mdb`, папка `Архив`, `CurrentDay.bin` — относительно `Environment.CurrentDirectory` (как в легаси).

## 5. Бизнес-правила и формулы
- Имя копии: `OperationDB-{UtcNow+3h:dd.MM.yyyy--HH-mm-ss-ffff}.mdb`.
- Автопроверка при старте: если `Today.Day < сохранённый день` → backup; затем сохранить текущий день.
- Восстановление «Авто»: последний файл `*.mdb` по `CreationTime`.
- Очистка архива: доступно `files.Count - 1`; ввод `0`/пусто/отмена — выход; нельзя удалить все файлы.
- Сообщения, заголовки и ru-RU — дословно из легаси.

## 6. Валидация и edge cases
- Нет `CurrentDay.bin`: день = -1, ошибка не показывается, файл создаётся при старте.
- Нет папки `Архив`: для restore — предупреждение и создание папки; для backup — ошибка копирования.
- В архиве нет `*.mdb`, но есть другие файлы: ошибка (как в легаси).
- Очистка архива: нечисловой ввод/превышение количества — сообщение, без удаления.
- Ошибки БД/файлов показываются пользователю русским текстом, приложение не падает.

## 7. Навигация и поведение окна
- Заголовок «Главное окно», стартовый размер 888×500.
- `MainWindow` — оболочка с `ContentControl`; дочерние экраны — `UserControl`.

- Закрытие главного окна завершает приложение.
