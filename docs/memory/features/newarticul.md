# Feature: newArticulForm (Новый артикул)

- Легаси: `newArticulForm.vb` (1–22); Designer — только контролы (24–123); вызов из `mainForm.vb:39–43`
- Цель: `Views/NewArticulView.xaml`, `ViewModels/NewArticulViewModel.cs`, `Data/INewArticulRepository`, `Data/NewArticulRepository`
- Статус: в работе (код готов; сборка/проверка на Windows не выполнены)
- Зависимости: `IDbConnectionFactory`, `IDialogService`, `INavigationService`; таблица `Articul`

## 1. Назначение и сценарии
Добавление нового артикула в справочник. Пользователь открывает форму из меню «Основные данные → Артикул»,
вводит название (`txtArt`) и описание (`txtDesc`), нажимает «Сохранить».
Успех — одна запись в `Articul` и сообщение «Новый Артикул <название> сохранен» с заголовком «Артикул».
«Закрыть» закрывает форму. Полей для просмотра/редактирования существующих артикулов нет.

## 4. Данные
- `INSERT INTO [Articul] ([ArticulName], [ArticulText]) VALUES (?, ?)`.
- `ArticulID` — счётчик Access, не передаётся.
- Параметры `ArticulName`, `ArticulText` — `VarWChar`, допускают NULL по схеме DBSet.
- Одиночный INSERT без транзакции; чтения/обновления после записи нет.

## 5. Бизнес-правила и формулы
- Валидации нет: пустые и пробельные значения передаются в БД как введены.
- Проверки дубликатов нет (как в легаси).
- Текст в БД и в сообщении — точное содержимое `txtArt.Text`, без trim.
- Сообщение показывается только если `INSERT` вернул > 0 строк.
- После сохранения поля не очищаются, форма не закрывается.
- Чисел, дат, округлений и культуры в сценарии нет.

## 6. Валидация и edge cases
- Успех: «Новый Артикул <название> сохранен» / «Артикул».
- Ошибка БД: в легаси исключение не перехватывается; в целевой версии — «Ошибка при сохранении артикула: » + `ex.Message` / «Ошибка» (отклонение, ADR-019).
- Пустые поля: разрешены, как в легаси (если БД не отклонит вставку).
- Дубликат названия: не проверяется; возможна вторая запись.
- `INSERT` вернул 0: сообщение не показывается.
- Очень длинное название/описание: длина полей 255 по `DBSet.xsd`; ограничение провайдера, как в легаси.

## 7. Навигация и поведение окна
Меню «Основные данные → Артикул» → `NewArticulViewModel` в `ContentControl` оболочки (ADR-007), не MDI.
«Закрыть» возвращает на приветственный экран (ADR-019), так как MDI-закрытия в WPF-оболочке нет.
Открытие немодальное; каждое открытие — новое состояние с пустыми полями.
