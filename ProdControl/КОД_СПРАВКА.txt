ОБРАБОТЧИКИ СОБЫТИЙ:
================================================================================

Когда пользователь меняет "Средн. зн.", срабатывает:
  tbAvgValue_TextChanged() → CalculateWithCoefficient()

Когда пользователь меняет коэффициент 1 или 2, срабатывает:
  cbCoeff1_SelectedValueChanged() → CalculateWithCoefficient()
  cbCoeff2_SelectedValueChanged() → CalculateWithCoefficient()

Когда пользователь меняет М или П, срабатывает:
  cbModelPartAmount_SelectedValueChanged() → CalculateWithKit()
  cbMachineCarriageAmount_SelectedValueChanged() → CalculateWithKit()


МЕТОДЫ РАСЧЁТОВ:
================================================================================

CalculateWithCoefficient()
  1. Берёт Средн.зн. из tbAvgValue
  2. Берёт Коэфф1 из cbCoeff1
  3. Берёт Коэфф2 из cbCoeff2
  4. Вычисляет: result = Средн.зн. × Коэфф1 × Коэфф2
  5. Выводит в tbWithCoefficient с форматом F3
  6. Вызывает CalculateWithKit() для пересчёта зависимого результата

CalculateWithKit()
  1. Берёт С коэфф из tbWithCoefficient
  2. Берёт М из cbModelPartAmount
  3. Берёт П из cbMachineCarriageAmount
  4. Вычисляет: result = С коэфф × М / П
  5. Выводит в tbWithKit с форматом F3

GetDecimalValue(value)
  1. Проверяет на Nothing → возвращает 0
  2. Преобразует в строку → убирает пробелы
  3. Заменяет запятую на точку
  4. Пытается преобразовать в Decimal
  5. Если ошибка → возвращает 0, не выбрасывая исключение


ПОТОКАМИ ДАННЫХ:
================================================================================

Пользователь вводит                    Система
──────────────────                    ────────
1. Выбирает Артикул
2. Выбирает Деталь
3. Выбирает Оборудование
4. Выбирает М                     → Event cbModelPartAmount_SelectedValueChanged
5. Выбирает П                     → Event cbMachineCarriageAmount_SelectedValueChanged
6. Выбирает Коэфф1               → Event cbCoeff1_SelectedValueChanged
7. Выбирает Коэфф2               → Event cbCoeff2_SelectedValueChanged
8. Вводит Средн.зн.              → Event tbAvgValue_TextChanged
									→ CalculateWithCoefficient()
									→ result1 = Средн.зн. × Коэфф1 × Коэфф2
									→ tbWithCoefficient = result1
									→ CalculateWithKit()
									→ result2 = result1 × М / П
									→ tbWithKit = result2
9. Форма готова ✓


ВАЛИДАЦИЯ И ОБРАБОТКА ОШИБОК:
================================================================================

Если Средн.зн. = 0
  → GetDecimalValue вернёт 0
  → CalculateWithCoefficient вернёт рано
  → tbWithCoefficient и tbWithKit очищаются

Если Коэфф1 = 0
  → coeff1 = 1 (используется 1 вместо 0)
  → Расчёт продолжается нормально

Если введена строка "abc"
  → GetDecimalValue вернёт 0 (TryParse вернёт false)
  → Расчёт обработает как 0
  → Исключение не выбросится

Если запятая вместо точки "1,5"
  → Заменяется на "1.5"
  → TryParse успешно парсит
  → Результат корректный


ПРИМЕРЫ ВЫЗОВОВ:
================================================================================

Пример 1: Пользователь меняет "Средн. зн." с 10 на 20

  TextChanged fired
  ↓
  tbAvgValue_TextChanged(sender, e)
  ↓
  CalculateWithCoefficient()
  {
	avgValue = 20
	coeff1 = 1.116
	coeff2 = 1.116
	result = 20 × 1.116 × 1.116 = 24.733
	tbWithCoefficient.Text = "24.733"
	CalculateWithKit()
	{
	  withCoeff = 24.733
	  М = 2
	  П = 2
	  result = (24.733 × 2) / 2 = 24.733
	  tbWithKit.Text = "24.733"
	}
  }

Пример 2: Пользователь меняет М с 2 на 3

  SelectedValueChanged fired
  ↓
  cbModelPartAmount_SelectedValueChanged(sender, e)
  ↓
  CalculateWithKit()
  {
	withCoeff = 24.733 (из предыдущего расчёта)
	М = 3
	П = 2
	result = (24.733 × 3) / 2 = 37.099 (с F3 → 37.099)
	tbWithKit.Text = "37.099"
  }


ТИПЫ ДАННЫХ:
================================================================================

Decimal     - для всех денежных и дробных расчётов (точность!)
String      - для текста в TextBox и результатов
Object      - для SelectedValue из ComboBox


КЛЮЧЕВЫЕ СЛОВА:
================================================================================

Handles     - регистрирует обработчик события на уровне компиляции
Try-Catch   - обработка ошибок
Return      - ранний выход из метода
If-Then     - условные ветвления


ФОРМАТИРОВАНИЕ:
================================================================================

F3          - формат 3 знака после запятой
			 Примеры:
			 1 → 1.000
			 1.5 → 1.500
			 1.23456 → 1.235 (округляется)
